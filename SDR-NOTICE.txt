Portable SDR components
=======================

AETV invokes rtl_sdr as a separate executable and dynamically loads libiio and libhackrf.
You may replace these components with compatible builds. The bundled binaries and build sources retain their own copyrights and licenses.

Windows packages include:
  RTL-SDR Blog V1.4.0 (GPL-2.0-or-later), including V4/V4L support:
    https://github.com/rtlsdrblog/rtl-sdr-blog/releases/tag/V1.4.0
  Analog Devices libiio v0.26 (LGPL-2.1-or-later), with libusb,
  libserialport (LGPL) and libxml2 (MIT):
    https://github.com/analogdevicesinc/libiio/releases/tag/v0.26
    https://github.com/analogdevicesinc/libiio/blob/v0.26/CI/publish_deps.ps1
  Zadig 2.9 / libwdi v1.5.1 USB setup utility (GPL/LGPL):
    https://github.com/pbatard/libwdi/releases/tag/v1.5.1
  Analog Devices Pluto/M2k USB driver installer v0.9 (vendor BSD license):
    https://github.com/analogdevicesinc/plutosdr-m2k-drivers-win/releases/tag/v0.9

License texts are in drivers/licenses; corresponding RTL-SDR, libiio and
Zadig/libwdi source archives are in drivers/sources. drivers/dependencies.json
records the exact upstream URLs and SHA-256 checksums. The USB installers are
provided for explicit first-time setup; AETV does not install system drivers
automatically. Microsoft runtime DLLs retain Microsoft's redistribution terms.

Linux packages include the distribution's rtl-sdr and libiio binaries and
linked dependencies. Their *-COPYRIGHT.txt files include the license texts,
copyright holders and upstream source locations. Build provenance is Ubuntu
22.04; the corresponding distribution sources are available at:
  https://archive.ubuntu.com/ubuntu/pool/universe/r/rtl-sdr/
  https://archive.ubuntu.com/ubuntu/pool/universe/libi/libiio/

See docs/sdr-portable-setup.md for the one-time operating-system USB setup.

HackRF additions (all portable variants)
---------------------------------------
libhackrf 2026.01.3 / library 0.9.2 uses the BSD-3-Clause license in its header.
The upstream tree also contains GPL-2.0-or-later tools/build files. Linux builds
compile the checksum-pinned official source archive; it and the license texts
are included in drivers/sources and drivers/licenses. No firmware is flashed.
  https://github.com/greatscottgadgets/hackrf/releases/tag/v2026.01.3

Windows uses checksum-pinned MSYS2 builds of libhackrf 2026.01.3-1, libusb
1.0.30-1 (LGPL-2.1-or-later), and libwinpthread
14.0.0.r375.g9c1abbbf5-1 (MIT/BSD). The libhackrf and libusb source packages
include the distribution build recipes. Winpthreads' license text is included.
Pluto and HackRF share the same libusb 1.0.30 DLL to avoid process-wide DLL
version conflicts. The original Pluto USB driver installer is unchanged.
The same pinned libusb and winpthreads replace older Hamlib copies and any
copies collected into PyInstaller's root. The Hamlib library itself is unchanged.
  https://packages.msys2.org/packages/mingw-w64-x86_64-hackrf
  https://packages.msys2.org/packages/mingw-w64-x86_64-libusb
  https://packages.msys2.org/packages/mingw-w64-x86_64-libwinpthread
